# Sepehr Falah — Personal Portfolio

A modern dark-themed front-end developer portfolio created for freelance presentation.

## Tech Stack
- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript
- Google Fonts

## Sections
- Hero / introduction
- About
- Skills & proficiency
- Selected projects
- Freelance services
- Contact form
- Social/profile links

## Customize
Update the GitHub, LinkedIn and Fiverr links in `index.html`.
Replace the fictional project links with your live project URLs when available.

## Run
Open `index.html` in a browser.

## Portfolio note
The layout and project descriptions are designed as a portfolio template. Replace placeholder profile links and project URLs before publishing.
